# Como usar o editor do site

Abra **Administração → Editar site**. Escolha a página e o dispositivo. **Computador** vale a partir de 900 px. **Celular** também atende tablets mais estreitos. Cada combinação guarda sua própria composição.

1. **Selecione na tela.** Clique no elemento ou procure seu nome em **Camadas**. Arraste para mover. As linhas indicam o encaixe. Use as alças para mudar o tamanho e segure Shift para manter a proporção. Clique no fundo para desmarcar.
2. **Edite o conteúdo.** Dê dois cliques em textos simples ou use **Propriedades**. Abra **Adicionar** para inserir um bloco. Selecione um card para experimentar **Vidro**, **Sólido** ou **Contorno**. **Mais opções** reúne medidas, cores e tipografia. O menu de cada camada permite travar, ocultar e ajustar a ordem. Os botões funcionais conservam a ação do site.
3. **Ajuste o celular.** Na primeira edição, você pode usar a disposição original ou **Gerar a partir do computador**. Essa opção empilha os elementos em ordem de leitura. Confira a altura das listas e o espaço entre textos após mudar a fonte.
4. **Confira e publique.** Aguarde **Rascunho salvo**, abra **Pré-visualizar** e teste os dois dispositivos. **Publicar** aplica todas as alterações do rascunho. Em **Problemas encontrados**, corrija os itens críticos e revise os avisos de contraste. Se outra pessoa tiver salvo primeiro, recarregue para trabalhar na versão mais recente.
5. **Para voltar.** **Desfazer/Refazer** atua durante a edição. **Voltar ao layout padrão** remove a composição da página e do dispositivo selecionados quando você publicar. Em **Tema, blocos e histórico**, você também pode restaurar uma versão como rascunho ou desfazer a última publicação.

**Atalhos.** Setas movem uma unidade. Shift + seta move dez. Alt + seta redimensiona. Shift + clique ou arraste no fundo seleciona vários elementos para alinhar ou distribuir. Ctrl+C/V/D copia, cola ou duplica. Delete exclui, Esc desmarca e Ctrl+Z/Y desfaz ou refaz. O botão **?** reabre o tour.

**O que muda em todo o site.** O fundo da página é específico do dispositivo. As fontes, as cores do tema e o logo são compartilhados. A prévia administrativa usa dados fictícios. Formulários de acesso, navegação, consentimento, rodapé legal e segurança da conta ficam sob controle do sistema.
